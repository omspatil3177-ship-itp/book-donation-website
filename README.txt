ABOUT THE BOOK GALLERY
The website describes the 100 donated books and their categories. The five photos
provided are actual project photos; they are not 100 individual book-cover photos.
To show 100 separate real book photos, upload photos of the individual books.
Do not use invented book-cover images as evidence of the books donated.

PRIVACY
Get permission from the school and parents/guardians before publishing identifiable
photos of children.


MOBILE-RESPONSIVE WEBSITE
=========================
This is a regular website, not a mobile app. It is designed to adapt to
desktop, tablet, Android phone, and iPhone browser screen sizes.

To use it:
1. Extract this ZIP file.
2. Keep index.html, style.css, script.js, and the images folder together.
3. Upload the contents of the book_donation_website folder to your web host.
4. Open your website address in a mobile browser to view the responsive layout.

The mobile navigation menu is touch-friendly. The page does not require
app installation or an APK.
